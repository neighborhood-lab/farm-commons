# Video Tutorial: Mobile App Usage Guide

## Metadata
- **Title:** Farm Commons Mobile App - Complete Guide
- **Duration:** 10-12 minutes
- **Target Audience:** Field workers, supervisors, farm managers
- **Prerequisites:** None (beginner-friendly)
- **Difficulty:** Beginner

## Learning Objectives

By the end of this video, viewers will be able to:
1. Install the Farm Commons mobile app
2. Log in and set up their profile
3. View their schedules on mobile
4. Clock in and out from the field
5. Use offline mode effectively
6. Understand location tracking features
7. Access certifications and documents
8. Navigate the mobile interface

**Q: Is the app free?**

A: Yes! Offline mode covered at 8:00

**Q: How much battery does it use?**
A: Minimal. Enable battery saver mode for all-day use

A: No, only when you clock in/out

**Q: What if I don't have a smartphone?**
A: Contact your farm manager about alternative options
