# Video Tutorial: Schedule Creation

## Metadata
- **Title:** Creating and Managing Schedules in Farm Commons
- **Duration:** 6-8 minutes
- **Target Audience:** Farm managers, supervisors
- **Prerequisites:** Understanding of workers and fields in the system
- **Difficulty:** Beginner

## Learning Objectives

By the end of this video, viewers will be able to:
1. Create new work schedules for workers
2. Assign workers to specific fields and tasks
3. View and edit existing schedules
4. Manage schedule conflicts
5. Understand schedule notifications

### Scene 3: Creating a Basic Schedule (2-3 minutes)

**NARRATION:**
"To create a new schedule, click the 'Add Schedule' button."

**ACTIONS:**
1. Click "Add Schedule" button
2. Schedule form opens

**NARRATION:**
"Let's create a schedule for tomorrow's harvest. First, we'll select the date and time."

**ACTIONS:**
1. Fill in basic schedule information:
   - **Date:** Select tomorrow's date from date picker
   - **Start Time:** Select "6:00 AM"
   - **End Time:** Select "2:00 PM"

**CALLOUTS:**
- Highlight the date picker interface
- Show the time selection dropdowns
- Display calculated duration (8 hours)

**NARRATION:**
"Next, we'll specify what task needs to be done and where."

**ACTIONS:**
2. Fill in task details:
   - **Task Type:** Select "Harvesting" from dropdown
   - **Field:** Select "North Field" from dropdown
   - **Description:** Type "Tomato harvest - bring extra crates"
   - **Priority:** Select "High"

**VISUAL:**
- Show the task type dropdown with common options
- Display field selector with field names
- Show the description text area
- Highlight priority indicator colors

**CALLOUTS:**
- "💡 Tip: Add specific instructions in the description"
- Point out that workers will see this description

**NARRATION:**
"Now let's assign workers to this schedule. Click the 'Add Worker' button to assign someone."

**ACTIONS:**
3. Assign workers:
   - Click "Add Worker" button
   - Worker selector appears
   - Type "Maria" in search box
   - Select "Maria Garcia" from results
   - Click "Add Worker" again
   - Select "Juan Rodriguez"
   - Select "Ana Martinez"

**VISUAL:**
- Show worker search functionality
- Display worker cards with photos/avatars
- Show selected workers list building up
- Display worker skills matched to task (green checkmark)

**CALLOUTS:**
- Highlight skill matching indicator
- "✓ Has required skills" badge
- Show estimated hours per worker

**NARRATION:**
"Great! Farm Commons shows us that all three workers have the harvesting skills needed for this task. Let's save this schedule."

**ACTIONS:**
4. Click "Create Schedule" button
5. Success notification appears
6. Return to calendar view with new schedule visible

**VISUAL:**
- Show the schedule appearing on the calendar
- Highlight it with animation
- Display the schedule card with all details

### Scene 5: Handling Schedule Conflicts (1-2 minutes)

**NARRATION:**
"Farm Commons helps you avoid scheduling conflicts. Let me show you what happens when you try to schedule a worker who's already assigned."

**ACTIONS:**
1. Click "Add Schedule" button
2. Set date to same as previous schedule (tomorrow)
3. Set time to "7:00 AM - 3:00 PM" (overlapping)
4. Select "Irrigation" task
5. Select "East Field"
6. Try to assign "Maria Garcia"

**VISUAL:**
- Conflict warning appears
- Show Maria's existing schedule in a tooltip
- Display warning icon with yellow/orange color

**CALLOUT:**
"⚠️ Maria Garcia is already scheduled for North Field from 6:00 AM - 2:00 PM"

**NARRATION:**
"The system alerts you that Maria is already scheduled during that time. You can either choose a different worker or adjust the timing."

**ACTIONS:**
7. Remove Maria from the assignment
8. Select "Carlos Lopez" instead (no conflict)
9. Green checkmark appears indicating availability

**VISUAL:**
- Show the conflict resolving
- Display green availability indicator
- Show Carlos in the workers list

**NARRATION:**
"Perfect! Carlos is available, so we can proceed with this schedule."

**ACTIONS:**
10. Click "Create Schedule"
11. Schedule is created successfully
