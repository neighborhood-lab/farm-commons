# Video Tutorial: Worker Management Walkthrough

## Metadata
- **Title:** Managing Workers in Farm Commons
- **Duration:** 8-10 minutes
- **Target Audience:** Farm managers, administrators
- **Prerequisites:** User account with manager or admin role
- **Difficulty:** Beginner

## Learning Objectives

By the end of this video, viewers will be able to:
1. Add new workers to the system
2. Edit worker information
3. Manage worker skills and certifications
4. View worker details and history
5. Deactivate workers when needed

### Audio Notes
- Use a friendly, instructional tone
- Pause briefly between major actions
- Speak at a moderate pace (not too fast)
- Enunciate clearly for non-native speakers
- Consider background music at 20% volume during intro/outro only

### Visual Effects
- Use subtle zoom (110%) when focusing on specific UI elements
- Add cursor highlight (yellow circle) for important clicks
- Use callout boxes with arrows for key information
- Fade transitions between scenes (0.3 seconds)
- Add chapter markers for easy navigation

### Accessibility
- Ensure all text on screen is readable at 720p
- Use high contrast for callouts
- Provide closed captions with timing
- Describe visual actions in narration
- Use consistent terminology throughout
