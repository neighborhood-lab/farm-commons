# Video Tutorial: Time Tracking Demo

## Metadata
- **Title:** Time Tracking in Farm Commons
- **Duration:** 5-7 minutes
- **Target Audience:** Workers, supervisors, farm managers
- **Prerequisites:** Basic understanding of the Farm Commons interface
- **Difficulty:** Beginner

## Learning Objectives

By the end of this video, viewers will be able to:
1. Clock in and clock out from work
2. Record break times
3. View their time entries
4. Edit time entries (supervisors)
5. Understand the verification process
6. Generate time reports

## Troubleshooting FAQ

Include in video description:

**Q: What if I forget to clock in?**
A: Contact your supervisor to add a manual entry

**Q: Can I edit my own time entry?**
A: No, only supervisors can edit for compliance reasons

**Q: How accurate is the time tracking?**
A: Timestamps are accurate to the second, displayed to the minute

**Q: What if I lose internet connection?**
A: Mobile app works offline and syncs when reconnected

**Q: How long are time entries stored?**
A: All entries are stored permanently for compliance
