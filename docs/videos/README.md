# Farm Commons Video Tutorials

This directory contains comprehensive scripts, storyboards, and guides for creating video tutorials that demonstrate the key features and workflows of the Farm Commons platform.

These video tutorials are designed to help users quickly understand and adopt the Farm Commons system. Each video focuses on a specific workflow or feature set, with clear objectives and step-by-step instructions.

## Video Production Guidelines

### Equipment Needed
- Screen recording software (OBS Studio, Camtasia, or ScreenFlow)
- Microphone for clear audio
- Video editing software
- Demo environment with realistic data

### Technical Specifications
- **Resolution:** 1920x1080 (1080p minimum)
- **Frame Rate:** 30 fps
- **Audio:** Clear voiceover in English and Spanish versions
- **Format:** MP4 (H.264 codec)
- **Aspect Ratio:** 16:9

### Style Guidelines
1. **Pacing:** Slow enough for viewers to follow, fast enough to maintain engagement
2. **Annotations:** Use callouts and highlights to draw attention to key UI elements
3. **Language:** Clear, simple language avoiding technical jargon
4. **Captions:** Include accurate subtitles for accessibility
5. **Music:** Optional soft background music, must not overpower narration

### Hosting & Distribution
- Upload to YouTube with public/unlisted visibility
- Embed in user documentation
- Make available offline for training sessions
- Provide downloadable versions for slow connections

## Recording Best Practices

### Preparation
1. **Clean demo environment:** Use realistic but clean sample data
2. **Browser setup:** Hide bookmarks bar, use consistent zoom level (100%)
3. **Script rehearsal:** Practice the script multiple times before recording
4. **Audio test:** Record a test clip to ensure clear audio
5. **Screen setup:** Close unnecessary applications, disable notifications

### During Recording
1. **Mouse movement:** Move cursor smoothly and deliberately
2. **Clicking:** Pause briefly before and after clicks to give viewers time to see
3. **Typing:** Type at a moderate pace, show what you're typing
4. **Navigation:** Explain what you're doing before doing it
5. **Errors:** If you make a mistake, pause, then restart that section

### Post-Production
1. **Edit out:** Long pauses, mistakes, loading times (unless relevant)
2. **Add:** Title screens, chapter markers, end cards
3. **Enhance:** Color correction, audio normalization
4. **Review:** Watch the full video to catch any issues
5. **Feedback:** Get 2-3 people to review before publishing

## Multilingual Support

All videos should be produced in both English and Spanish:
- **English version:** Default narration
- **Spanish version:** Dubbed or re-recorded narration with Spanish subtitles

Consider providing subtitle files in additional languages:
- Portuguese
- Haitian Creole
- Other languages based on user demographics

## Update Schedule

Videos should be reviewed and updated:
- **Major updates:** When UI significantly changes
- **Minor updates:** When new features are added
- **Quarterly review:** Check for accuracy and relevance
- **Version tracking:** Tag videos with application version number

## Metrics & Feedback

Track the following to improve video quality:
- View count and completion rate
- User feedback and ratings
- Support ticket reduction for covered topics
- Time to onboard new users
