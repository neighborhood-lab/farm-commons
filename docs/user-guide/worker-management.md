## Viewing Workers

### Accessing the Workers Page

1. Log in to Farm Commons
2. Click **"Workers"** in the main navigation menu
3. You'll see a list of all workers on your farm

### Workers List View

The Workers page displays:

- **Name** - Worker's full name
- **Role** - Position (e.g., Field Worker, Equipment Operator, Manager)
- **Phone** - Contact phone number
- **Email** - Email address
- **Status** - Active or Inactive
- **Actions** - Edit or view details

### Filtering and Searching

**Search workers:**
- Use the search box to find workers by name, email, or phone number
- Search is real-time and case-insensitive

**Filter by status:**
- **All Workers** - Show everyone
- **Active Only** - Show currently employed workers
- **Inactive Only** - Show former workers

## Adding a New Worker

### Prerequisites

**Required permissions:** Manager or Admin role

### Steps to Add a Worker

1. Navigate to the **Workers** page
2. Click the **"Add Worker"** button (top right)
3. Fill in the worker information form
4. Click **"Save"** to create the worker

### Required Information

**Personal Information:**
- **First Name** (required)
- **Last Name** (required)
- **Email Address** (required, must be unique)
- **Phone Number** (required)
- **Role** (required) - Select from dropdown

**Optional Information:**
- **Date of Birth** - For age verification and compliance
- **Hire Date** - When the worker started
- **Address** - Mailing address
- **Emergency Contact** - Name and phone number

### Worker Roles

Select the appropriate role for the worker:

- **Worker** - Standard farmworker, can view own schedules and clock in/out
- **Manager** - Can manage workers, schedules, and verify time entries
- **Admin** - Full access to all features and settings

**Important:** Be careful when assigning Manager or Admin roles, as they have access to sensitive data.

## Editing Worker Information

### Updating Worker Details

1. Go to the **Workers** page
2. Find the worker you want to edit
3. Click the **"Edit"** button (pencil icon) next to their name
4. Update the information in the form
5. Click **"Save Changes"**

### What Can Be Edited

**You can update:**
- Contact information (email, phone, address)
- Role and position
- Skills and certifications
- Emergency contacts
- Status (Active/Inactive)

**You cannot change:**
- Worker ID (automatically assigned)
- Historical time entries or schedules

## Skills and Certifications

### Why Track Skills?

Tracking worker skills helps you:
- **Assign appropriate tasks** - Match workers to jobs they're qualified for
- **Ensure compliance** - Track required certifications (e.g., pesticide applicator license)
- **Plan training** - Identify skill gaps
- **Improve safety** - Verify workers have necessary safety training

### Adding Skills

1. Edit a worker's profile
2. Scroll to the **"Skills"** section
3. Select skills from the dropdown or add custom skills
4. Click **"Save Changes"**

### Common Farm Skills

- Tractor Operation
- Irrigation Management
- Harvesting
- Planting
- Pruning
- Equipment Maintenance
- Food Safety (GAP certified)
- Organic Certification Knowledge
- Pesticide Application (with license)

### Certifications

**Adding Certifications:**
1. Edit worker profile
2. Go to **"Certifications"** section
3. Click **"Add Certification"**
4. Enter certification details:
   - Certification name
   - Issuing organization
   - Issue date
   - Expiration date
   - Certificate number
5. Upload certification document (if available)
6. Click **"Save"**

**Certification Expiry Alerts:**

Farm Commons will alert you when certifications are expiring:
- **90 days** - Yellow warning
- **60 days** - Orange warning
- **30 days** - Red alert
- **Expired** - Red with urgent flag

## Emergency Contacts

### Adding Emergency Contact

For each worker, you should record emergency contact information:

1. Edit the worker's profile
2. Scroll to **"Emergency Contact"** section
3. Enter:
   - Contact name
   - Relationship to worker
   - Phone number
   - Alternate phone number (optional)
4. Click **"Save Changes"**

**Why it matters:** In case of workplace injury or emergency, you need to be able to reach someone quickly.

**Privacy note:** Emergency contact information is visible only to Managers and Admins.

## Deactivating Workers

### When to Deactivate

Deactivate a worker when they:
- Leave the farm (quit or terminated)
- Are on extended leave
- No longer need system access

**Important:** Don't delete workers - deactivate them instead. This preserves historical data for payroll, compliance, and reporting.

### How to Deactivate

1. Edit the worker's profile
2. Find the **"Status"** field
3. Change from **"Active"** to **"Inactive"**
4. Click **"Save Changes"**

### What Happens When Deactivated

- Worker **cannot log in** to Farm Commons
- Worker **does not appear** in schedule assignments
- **Historical data is preserved** (time entries, schedules)
- Worker **can be reactivated** at any time

### Reactivating a Worker

1. Go to Workers page
2. Filter by **"Inactive Only"**
3. Find the worker
4. Edit their profile
5. Change status to **"Active"**
6. Save changes

## Common Workflows

### Seasonal Worker Onboarding

**Scenario:** You're hiring 10 seasonal workers for harvest season.

**Steps:**
1. Prepare worker information (collect I-9s, contact info)
2. Add all workers in Farm Commons
3. Assign **"Worker"** role to each
4. Record emergency contacts
5. Add relevant skills (e.g., Harvesting)
6. Upload any required certifications
7. Create schedules for their start date

**Tip:** Add workers a few days before they start so schedules are ready on day one.

---

### Managing Certifications

**Scenario:** You need to track pesticide applicator licenses for 5 workers.

**Steps:**
1. For each worker with a license:
   - Edit their profile
   - Add certification: "Pesticide Applicator License"
   - Enter expiration date
   - Upload copy of license
2. Set up reminders for renewal (30 days before expiration)
3. Check Dashboard weekly for expiring certifications

**Compliance note:** Many certifications are required by law. Keep copies of all certificates on file.

---

### Worker Promotion

**Scenario:** A worker is promoted to crew lead (Manager role).

**Steps:**
1. Edit the worker's profile
2. Change role from **"Worker"** to **"Manager"**
3. Update their position/title
4. Inform the worker of their new permissions
5. Provide training on Manager features (scheduling, time verification)

**Important:** Manager role gives access to all farm data and other workers' personal information. Only promote trusted employees.

---

### End of Season Offboarding

**Scenario:** Harvest is complete, seasonal workers are leaving.

**Steps:**
1. Verify all time entries are completed
2. Generate payroll reports
3. Process final paychecks
4. Deactivate seasonal workers
5. Archive documentation
6. Note in their profile if they're eligible for rehire

**Tip:** Keep detailed notes on worker performance for next season.

## Best Practices

### Data Entry

- ✅ **Be consistent** - Use same format for all workers (e.g., phone numbers)
- ✅ **Verify information** - Double-check email addresses and phone numbers
- ✅ **Keep it current** - Update contact info when workers notify you of changes
- ✅ **Document everything** - Add notes about special accommodations or situations

### Privacy and Security

- ✅ **Limit access** - Only Managers and Admins should access worker personal data
- ✅ **Respect privacy** - Don't share worker information with unauthorized people
- ✅ **Secure devices** - Log out when using shared computers
- ✅ **Regular audits** - Review worker list quarterly to remove outdated accounts

### Compliance

- ✅ **Track certifications** - Especially licenses required by law
- ✅ **Set up alerts** - Get notified before certifications expire
- ✅ **Keep records** - Upload copies of certificates and training records
- ✅ **Annual review** - Check all worker data annually for accuracy

## Troubleshooting

### Common Issues

**Problem:** Can't add a worker - "Email already exists"
- **Solution:** Email addresses must be unique. Check if worker already has an account, or use a different email.

**Problem:** Worker can't log in after being added
- **Solution:** Verify the email address is correct. Have the worker check spam folder for login credentials.

**Problem:** Worker not appearing in schedule assignment dropdown
- **Solution:** Check that worker status is "Active". Inactive workers don't appear in schedules.

**Problem:** Certification expiry alert not showing
- **Solution:** Verify expiration date is entered correctly. Check Dashboard for alerts.

## Frequently Asked Questions

**Q: How many workers can I add?**
- A: There's no hard limit. Farm Commons is designed for small to medium farms (typically 5-100 workers).

**Q: Can workers see other workers' information?**
- A: No. Workers can only see their own information. Managers and Admins can see all workers.

**Q: Can I bulk import workers from a spreadsheet?**
- A: Not yet, but this feature is planned for Phase 2. For now, add workers individually.

**Q: What happens to worker data if they're deactivated?**
- A: All data is preserved. You can reactivate them anytime and their history remains intact.

**Q: Can I customize worker roles?**
- A: Currently, there are three fixed roles (Worker, Manager, Admin). Custom roles are planned for future phases.
